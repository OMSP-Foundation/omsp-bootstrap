# OMSP Release Management

## Release Yaklaşımı

İlk aşamada hafif release yönetimi kullanılacaktır.

## Versiyonlama

Önerilen yapı:

```txt
v0.1.0
v0.2.0
v1.0.0
```

## Release Hazırlığı

Her release öncesi:

- [ ] Açık kritik bug var mı kontrol edilir
- [ ] Milestone tamamlanma durumu kontrol edilir
- [ ] Changelog güncellenir
- [ ] Release notu hazırlanır

## Changelog Formatı

```md
## v0.1.0

### Added
- 

### Changed
- 

### Fixed
- 
```
