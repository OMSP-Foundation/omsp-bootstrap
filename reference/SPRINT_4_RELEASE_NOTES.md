# Sprint 4 Release Notes

- Artifact ID: `OMSP-REFERENCE-SPRINT4-RELEASE-NOTES-0001`
- Proposed version: `0.4.0`
- Release type: documentation-level foundation baseline
- Status: `review`

## Summary

Sprint 4 establishes the first governed OMSP digital-twin foundation baseline for vessel references, equipment and interfaces, operational scenarios, observations and state, demonstrator evidence, and governance boundaries.

## Added

- governed vessel reference model;
- Hanse 460 design-family reference configuration;
- equipment and interface taxonomy and examples;
- normal, degraded, emergency, maintenance and validation scenario structures;
- immutable observation and reproducible current-state rules;
- derived-value provenance requirements;
- static interoperability demonstrator and traceability evidence;
- authority, accountability, escalation and AI-assistance boundaries;
- Sprint 4 baseline and release-readiness controls.

## Validated

- model layers can be linked without collapsing their authority boundaries;
- stale, missing and conflicting evidence remains visible;
- derived outputs remain advisory and provenance-complete;
- accountable human authority remains explicit;
- illustrative Hanse 460 records do not create as-built claims.

## Release limitations

Version `0.4.0` is not:

- a production runtime;
- a live telemetry platform;
- an approved navigation or emergency system;
- a vessel-specific digital twin;
- a certified configuration baseline;
- a vessel-control or autonomous-navigation authorization.

## Compatibility

This release is a documentation baseline. Future schemas or runtime implementations must preserve stable identifiers, provenance, authority separation and governance controls, or document and approve a breaking change.
