# OMSP Chat Command Reference

Bu repo ChatGPT üzerinden şu komutlarla yönetilebilir.

## Issue

```txt
Yeni issue aç: ...
#12 issue'yu güncelle: ...
#12 issue'ya yorum ekle: ...
#12 issue'yu kapat
```

## Sprint

```txt
Sprint 1 için açık işleri listele
Sprint 0 için kalan işleri özetle
Bu issue'yu Sprint 1'e al
```

## Repo

```txt
Son PR'ları incele
Repo dokümantasyonunu güncelle
Yeni dosya ekle
```

## Not

GitHub Project item alanlarını doğrudan güncelleme aracı mevcut değilse, Project panosundaki field değişiklikleri GitHub arayüzünden yapılır. Issue içerikleri ve repo dosyaları buradan yönetilebilir.
