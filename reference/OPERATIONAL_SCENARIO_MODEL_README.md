# Operational Scenario Model Package

This package contains the governed Sprint-4 scenario contract and illustrative examples for WP-0042.

## Files

- `OPERATIONAL_SCENARIO_MODEL.md` — normative scenario entity, authority, traceability and safety rules.
- `operational-scenario-model.examples.json` — illustrative normal, degraded and emergency Hanse 460 design-family mappings.
- `OPERATIONAL_SCENARIO_VALIDATION_CHECKLIST.md` — review checklist for scenario conformance and authority boundaries.

## Intended Use

Use the package to create reusable scenario definitions that reference governed vessel, system, equipment, interface, procedure and evidence identities. Treat all included examples as design-family reference material only.

## Prohibited Interpretation

The package is not a live operating manual, emergency procedure, navigation instruction, maintenance instruction, certification record or authorization for autonomous control. Approved vessel-specific procedures and accountable human judgement always prevail.

## Downstream Dependencies

WP-0043 may reference scenario and step identities when defining state and observation records. WP-0044 may use bounded examples for a non-operational demonstrator after explicit review.
