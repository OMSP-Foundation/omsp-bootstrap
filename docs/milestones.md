# OMSP Milestones

GitHub Milestones için önerilen başlangıç yapısı:

## Sprint 0 - Foundation Setup

**Amaç:** Project, issue, PR ve repo yönetim altyapısını kurmak.

**Önerilen due date:** Kısa kurulum sprint'i olarak 1 hafta.

## Sprint 1 - Bootstrap MVP

**Amaç:** `omsp-bootstrap` reposunu minimum kullanılabilir geliştirme zemini haline getirmek.

## Sprint 2 - Core Workflow

**Amaç:** OMSP genelinde tekrar edilebilir issue/PR/release akışı kurmak.

## Milestone Kullanım Kuralı

- Sprint'e alınan her issue ilgili milestone'a bağlanır.
- Sprint dışı işler milestone'suz kalabilir veya Backlog milestone'una alınabilir.
- Sprint sonunda milestone kapatılır, taşan işler sonraki milestone'a aktarılır.
