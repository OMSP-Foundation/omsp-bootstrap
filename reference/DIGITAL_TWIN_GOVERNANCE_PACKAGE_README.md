# Digital Twin Governance Package

This package defines authority, approval, accountability, escalation, AI-assistance, and change-review boundaries for OMSP digital-twin artifacts.

## Files

- `DIGITAL_TWIN_GOVERNANCE_AND_SAFETY_BOUNDARIES.md` — governing policy
- `DIGITAL_TWIN_AUTHORITY_MATRIX.md` — artifact and role authority matrix
- `DIGITAL_TWIN_AI_ASSISTANCE_BOUNDARIES.md` — permitted, restricted, and prohibited AI use
- `DIGITAL_TWIN_GOVERNANCE_CHANGE_REVIEW_CHECKLIST.md` — review and acceptance controls
- `digital-twin-governance.example.json` — machine-readable governance example

## Core rule

Configuration facts, observations, projected state, derived advisory values, approved procedures, and operational authority remain separate. Accountable human authority is explicit and cannot be silently transferred to software or AI.

## Non-goals

This package does not grant certification, seaworthiness, regulatory acceptance, runtime approval, or authorization to control a vessel.
