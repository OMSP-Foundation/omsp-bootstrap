# Equipment and Interface Model Package

This directory package for WP-0041 contains:

- `EQUIPMENT_AND_INTERFACE_MODEL.md` — governed conceptual model;
- `equipment-interface-model.example.json` — illustrative machine-readable records;
- `EQUIPMENT_INTERFACE_VALIDATION_CHECKLIST.md` — review and acceptance checklist.

The package extends the generic vessel and Hanse 460 design-family reference models. It does not assert manufacturer-specific equipment, option-package content or installed vessel facts.
