# Sprint 1 Candidate Scope

## Hedef

`omsp-bootstrap` reposunu OMSP için minimum kullanılabilir geliştirme zemini yapmak.

## Aday İşler

- Bootstrap repo amacını README içinde netleştir
- Development branch akışını uygula
- Minimum CI/check akışını kur
- İlk katkı dokümantasyonunu doğrula
- Project board üzerinden sprint takibini başlat

## Definition of Done

- Sprint 1 issue'ları oluşturuldu
- Milestone'a bağlandı
- Project panosunda görünür
- En az bir PR akışı tamamlandı
