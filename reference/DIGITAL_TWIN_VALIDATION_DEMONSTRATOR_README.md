# Digital Twin Validation Demonstrator Package

This package validates documentation-level interoperability across the Sprint-4 vessel, equipment/interface, operational scenario, and state/observation models.

## Files

- `DIGITAL_TWIN_VALIDATION_DEMONSTRATOR.md` — use case and replay procedure
- `digital-twin-validation-demonstrator.example.json` — static replay manifest
- `DIGITAL_TWIN_VALIDATION_TRACEABILITY.md` — end-to-end traceability matrix
- `DIGITAL_TWIN_VALIDATION_CHECKLIST.md` — review and acceptance controls
- `DIGITAL_TWIN_VALIDATION_LIMITATIONS.md` — explicit capability and claim boundaries

## Demonstrated behavior

The package shows how a Hanse 460 design-family reference configuration can be linked to illustrative equipment roles, a degraded navigation-data scenario, immutable observations, a reproducible current-state projection, and a provenance-complete advisory result.

## Non-goals

The package does not implement live telemetry, vessel control, production storage, operational procedures, certification, or a vessel-specific digital twin.
