# OMSP Backlog

Bu dosya, ilk ürün/backlog fikirlerinin izlenmesi içindir. Asıl takip GitHub Issues ve OMSP Roadmap Project panosunda yapılır.

## Sprint 0 - Foundation Setup

- GitHub Project panosunu repo issue/PR akışına bağla
- Issue/PR şablonlarını tamamla
- Label ve milestone standardını netleştir
- Development branch stratejisini tanımla
- İlk Sprint 1 kapsamını çıkar

## Sprint 1 - Bootstrap MVP

- Bootstrap repo amacını netleştir
- Minimum çalışır proje iskeletini doğrula
- CI/check akışını başlat
- Katkı/development dokümantasyonu ekle

## Sprint 2 - Core Workflow

- Issue → branch → PR → review → merge standardı
- Release ve changelog standardı
- Çok repo yönetim modeli
