# Contributing to OMSP

## Çalışma Akışı

1. Issue seçilir veya açılır
2. Issue için branch oluşturulur
3. Değişiklik yapılır
4. Pull request açılır
5. Review tamamlanır
6. Merge edilir

## Branch Formatı

```txt
feature/<issue-number>-short-name
bugfix/<issue-number>-short-name
task/<issue-number>-short-name
```

## PR Açarken

- PR template doldurulmalı
- İlgili issue bağlanmalı
- Değişiklikler kısa ve net açıklanmalı

## Issue Açarken

- Issue template kullanılmalı
- Kabul kriterleri yazılmalı
- Gerekirse priority ve area belirtilmeli
