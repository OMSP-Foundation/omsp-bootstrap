# OMSP Canon Index

## 1. Purpose

This index provides the entry point and recommended reading order for OMSP canon artifacts.

It helps downstream artifacts reference the correct canon source for identity, purpose, philosophy, principles, terminology, and ontology concepts.

## 2. Recommended Reading Order

1. [Vision](./VISION.md) — long-term direction and intended future state.
2. [Mission](./MISSION.md) — program purpose and mission outcomes.
3. [Philosophy](./PHILOSOPHY.md) — interpretive stance for OMSP work.
4. [Principles](./PRINCIPLES.md) — operating rules for design, governance, review, and evolution.
5. [Terminology](./TERMINOLOGY.md) — canonical vocabulary for downstream artifacts.
6. [Ontology Overview](./ONTOLOGY_OVERVIEW.md) — foundational concept and relation families.

## 4. Downstream Reference Guidance

Downstream artifacts should reference canon artifacts when they need to:

- explain strategic or mission alignment;
- define or use canonical terminology;
- justify model-based engineering choices;
- establish traceability expectations;
- interpret governance or artifact standards;
- introduce domain concepts or relation families.

## 5. Maintenance

This index is maintained through issue-backed Work Packages and reviewed pull requests. Material changes require governance review and version metadata update.
