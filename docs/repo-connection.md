# Repo Connection Plan

Bu doküman, OMSP Roadmap Project panosuna bağlanacak repoları izlemek için kullanılır.

## Bağlı Repo

- `OMSP-Foundation/omsp-bootstrap`

## Eklenecek Repo Kontrol Listesi

Her yeni repo için:

- [ ] GitHub App erişimi var mı?
- [ ] Issue templates eklendi mi?
- [ ] PR template eklendi mi?
- [ ] Project auto-add workflow kapsamına alındı mı?
- [ ] Label standardı uygulandı mı?
- [ ] Milestone standardı uygulandı mı?

## Project Auto-add Filter

Tüm repo issue/PR'ları için project workflow tarafında önerilen filtre:

```txt
is:issue OR is:pr
```

Birden fazla repo bağlandığında project workflow içinde her repo ayrı seçilmelidir.
