# OMSP Sprint Plan

## Sprint 0 - Foundation Setup

**Hedef:** OMSP için GitHub tabanlı proje yönetimi altyapısını kurmak.

### Kapsam

- GitHub Project panosu oluşturuldu
- Repo project workflow dokümantasyonu eklendi
- Issue template yapısı eklendi
- PR template eklendi
- Label standardı belgelendi
- İlk backlog çıkarıldı

### Definition of Done

- Project panosu repo issue/PR akışına bağlı
- Yeni issue'lar project panosuna düşüyor
- Sprint 1 kapsamı issue olarak açılmış

## Sprint 1 - Bootstrap MVP

**Hedef:** `omsp-bootstrap` reposunu OMSP'nin ilk çalışır geliştirme zemini haline getirmek.

### Aday Kapsam

- Repo amacı ve kullanım dokümantasyonu
- Development branch standardı
- Minimum CI/check akışı
- Katkı standardı

## Sprint 2 - Core Workflow

**Hedef:** OMSP genelinde tekrar edilebilir geliştirme ve release akışı kurmak.

### Aday Kapsam

- Issue → branch → PR → review → merge akışı
- Release notları
- Çok repo project yönetimi
