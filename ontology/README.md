# OMSP Ontology

This directory contains the governed Sprint-2 formal ontology artifacts.

- [`OMSP_ONTOLOGY.md`](OMSP_ONTOLOGY.md) — normative human-readable ontology.
- [`MARITIME_ONTOLOGY.md`](MARITIME_ONTOLOGY.md) — maritime domain extension of the core ontology (registry entries marked `layer: maritime`).
- [`omsp-ontology.json`](omsp-ontology.json) — machine-readable concept and relation registry.
- [`CANON_ONTOLOGY_MAPPING.md`](CANON_ONTOLOGY_MAPPING.md) — traceability from canonical terminology and overview families to ontology identities.

The ontology is technology-neutral. OWL, RDF and SHACL serializations remain deferred until a governed downstream requirement justifies them.
